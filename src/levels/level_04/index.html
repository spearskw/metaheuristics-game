Level 4

A new strategy!

Hill climb uses the same step size every time. But what if you could start with big steps to explore, then take smaller steps to get precise?

That's the Adaptive strategy. Try both on different maps and see which one works better!

Strategies

Hill Climb
Takes a random step left or right each turn. Only accepts the new position if it's better. Simple but can get stuck.
Adaptive
Starts with big steps to explore broadly, then gradually shrinks them to zero in on the best spot. Only accepts improvements.
